# macOS / DiscordLocalDPI

Kurulum, site listesi, servis yönetimi ve kaldırma için [macOS rehberini](../docs/macos.md) okuyun.

SpoofDPI 1.5.3 kullanılır. Apple Silicon ve Intel indirme seçenekleri vardır. Kaynak kullanıcı rehberi Apple Silicon üzerinde çalışan kurulumu anlatır; bu repodaki yeni kurulum betikleri Mac üzerinde henüz denenmemiştir.
